# Жилой район «Возрождение» — продажа земельного массива

Земельный массив под индивидуальное жилищное строительство (ИЖС) на берегу р. Воронеж. Продаётся **целиком одному покупателю** вместе с мастер-планом, архитектурной концепцией и инженерной подготовкой.

- **Сайт:** https://vozrozhdenie-life.ru/

- **Инвестиционный тизер (PDF):** [assets/docs/vozrozhdenie-teaser.pdf](assets/docs/vozrozhdenie-teaser.pdf)

## Почему этот актив

1. **Земля уже собрана.** Все участки принадлежат одному собственнику: покупателю не нужно договариваться с десятками владельцев.
2. **Инженерная подготовка сделана.** Асфальтированный подъезд, мост через р. Воронеж (введён в эксплуатацию 01.11.2020), электричество 12,5 кВт на участок, газ на территории.
3. **Концепция и продукт уже есть.** Мастер-план, единый архитектурный регламент, серийная линейка деревянных домов 70 / 95 / 120 м², построенный демонстрационный дом.
4. **Сделка простая.** В периметре только жилая застройка и её инфраструктура, поэтому ниже порог входа, а due diligence и закрытие проходят быстрее.
5. **Рядом работающее село.** В 2,5 км от массива в с. Преображеновке есть школа, детский сад, бассейн, спорткомплекс, ФАП, магазины и пляж. Село шесть раз (2011–2020) побеждало во всероссийском конкурсе на самое благоустроенное сельское поселение.
6. **Потенциал роста.** По расширенной концепции можно выйти на 223–227 домовладений после межевания резервных зон. Рекомендуемая первая очередь — 20–30 участков.

**Расстояния:** Липецк — 64 км, Мичуринск — 50 км, Тамбов — 120 км, Москва — ≈400 км.

## Для разработчиков

### Структура репозитория

- `index.html` — главная страница
- `teaser.html` — инвестиционный тизер (веб-версия)
- `investors.html`, `banks.html`, `buyers.html`, `instabuyers.html` — внутренние CRM-трекеры рассылок инвесторам, банкам и покупателям (статусы хранятся в localStorage, страницы закрыты от индексации `noindex`)
- `assets/css/` — стили (`style.css` общий, остальные — для отдельных страниц)
- `assets/js/` — `main.js` (мобильное меню, визиты, форма обратной связи через Telegram), `*-data.js` и `*.js` для трекеров
- `assets/img/` — фотографии и логотип
- `assets/video/` — видео с площадки
- `assets/docs/` — PDF для скачивания (тизер, ПЗЗ, кадастровая карта)
- `build/teaser_pdf.py` — генератор PDF-тизера
- `robots.txt`, `sitemap.xml`, `CNAME` — индексация и кастомный домен

### Пересборка PDF-тизера

PDF собирается скриптом, а не печатью страницы из браузера: A4, строгий стиль, серая палитра, шрифт Roboto из `C:\Windows\Fonts`.

```bash
pip install reportlab pillow
python build/teaser_pdf.py   # → assets/docs/vozrozhdenie-teaser.pdf
```

Цифры (цена, площади, количество участков) заданы в скрипте вручную. Если они меняются, правьте и `build/teaser_pdf.py`, и `teaser.html`, и таблицу в этом README.

### Публикация на GitHub Pages

1. **Settings → Pages → Build and deployment → Source: Deploy from a branch**.
2. Branch: `main`, папка `/ (root)`.
3. Custom domain: `vozrozhdenie-life.ru` (файл `CNAME` в корне).
4. Через 1–2 минуты сайт доступен на https://vozrozhdenie-life.ru/.

Локальный просмотр: открыть `index.html` в браузере или запустить `python -m http.server` в корне репозитория.
